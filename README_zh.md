# FoldLimbs

| [en](./README.md) | **zh_cn** |
|---|---|

原版rimworld中安装仿生臂或仿生腿将替换pawn的原生肢体。本mod提供另一个安装仿生体时禁用并束缚原有肢体的选项，并允许卸除仿生体并恢复原有肢体的功能。被禁用的原生肢体部件效率为0，但仍会受伤并疼痛（可在mod设置中关闭）

## Features

增加了以下手术类型：

- 禁用肢体
- 安装放生体（不移除原有肢体）
- 恢复肢体

此外，修改了原版移除仿生体的逻辑：原版的移除逻辑为用 99999 伤害把整个肢体直接摧毁（连带 `Hediff_AddedPart` 一起移除），本mod在同时拥有 `Restraint and Disabled和`仿生体状态下进行移除仿生体手术时，只会移除仿生体的附加状态


### 伤害计算

以上的定义部分问题不大，但涉及到伤害计算就相当蛋疼。因为在原版中`肩/腿`身体部位只能表达一种肢体，而在本Mod中，`肩/腿`身体部位则同时承担了仿生体和原肢体的定义。而依照原版逻辑，任何落在仿生肢体上的伤害都会继承`Solid`属性，转化为仿生体特有的不疼痛和流血的伤害。

本mod尽力模拟了一套伤害系统，所有仿生体受到的伤害都被重新定义了一类新的hediff（仿生体xx伤/bionic xxx），各个肢体部位被伤害时，有默认0.8概率转换为对应的仿生体伤害类型，并附加于`肩/腿`身体部位。这个概率可以在设置中调整。当`肩/腿`身体部位血量清空时，将移除仿生体状态（仿生体被摧毁）并清除所有仿生体伤害，然后重新计算部位的血量（当然，如果伤害全部不是仿生体伤害，则重新计算血量后原有部位依旧会被摧毁）。冻伤/灼伤不受该机制影响，会同时伤害仿生体和原有肢体。

这个机制并不完全合理，例如`肩/腿`身体部位原有肢体受伤会影响仿生体效率，以及`肩/腿`身体部位原有肢体严重受伤时，受到少量仿生体伤害导致的部位血量清空也会触发仿生体摧毁，如果你有更好的思路请告诉我


### 兼容性：

显而易见，此mod与任何修改了仿生体手术逻辑的mod都不兼容，且无兼容的计划

此mod与所有改写伤害行为的mod都不兼容（例如Combat extension）

应该可以被安全加入至存档，但建议额外备份存档

> 你可以使用开发者模式来恢复已经被移除原有肢体的殖民者的肢体，并重新使用本mod提供的手术配方
